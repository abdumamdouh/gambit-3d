I wanted to get better at chess, so I built my own coach. ♟️

Gambit 3D is a cinematic 3D chess game that teaches:
• Play Stockfish at 8 levels, right in the browser
• A blunder guard that stops bad moves before you make them
• Game reviews that explain every mistake in plain words
• A coach that learns my style across games and turns my own mistakes into lessons
• Lessons from zero, real Lichess puzzles, 4 board styles — free, open source, works offline

Built in one day with Claude Code — idea → spec → tested, deployed app (213 unit + 16 end-to-end tests).
